Design Rationale
Why We Chose Each Technology
Why Next.js 16?

App Router enables server components for fast initial loads. Turbopack speeds up dev iteration. Vercel deployment is seamless — no config needed for edge delivery.

Why Three.js + R3F?

Three.js is the industry standard for browser WebGL. React Three Fiber turns 3D into declarative JSX — the same component model we already know, applied to 3D.

Why satellite.js (SGP4)?

SGP4 is the exact algorithm used by NORAD and CelesTrak. Our orbit predictions are mathematically identical to real-world tracking systems.

Why Web Workers?

Trajectory propagation for hundreds of satellites is CPU-heavy. Offloading to orbitalWorker.ts keeps the main thread free — preserving 60 FPS regardless of compute load.

Why Zustand?

1KB, zero boilerplate. Handles complex shared state between radar globe, sidebar filters, time-machine, and user location — without Redux overhead.

Why Tailwind CSS v4?

Utility classes allow pixel-perfect glassmorphism and neon glow effects at speed. v4's native CSS variables enable our custom design tokens to cascade naturally.

Technical Deep Dive
Advanced Bundler Config — The Hard Parts
❌ Problem
WebAssembly in Next.js 16

satellite.js uses em-pthread WebAssembly importing Node.js modules (worker_threads, module). Turbopack throws UnhandledSchemeError in browser.

✅ Fix
Turbopack + Webpack Hybrid

turbo.resolveAlias maps node: schemes to empty.js in dev. In production, Webpack NormalModuleReplacementPlugin strips illegal prefixes.

❌ Problem
RSC Bailout Crashes Three.js

WebGL Canvas uses useSearchParams() from next/navigation. RSC boundaries cause bailout errors that crash the Three.js context entirely.

✅ Fix
Client-Side Suspense Isolation

Canvas initializations wrapped in Suspense boundaries. Three.js kept in pure client components, fully isolated from RSC.

❌ Problem
Three.js Barrel Export Leaks

three and @react-three use barrel exports causing memory leaks during Next.js server-side bundling due to module graph over-inclusion.

✅ Fix
transpilePackages

next.config.ts forces Next.js to fully transpile three and @react-three, eliminating barrel-export memory leaks in production.
